# Love It Forward

Single-file static site. All three pages live in `index.html` and switch by hash:

- `#home`
- `#brands`
- `#about`

Fonts, photographs, textures, CSS and JavaScript are embedded. No build step, no dependencies.

## Netlify
Drag this folder onto https://app.netlify.com/drop, or connect the repo and leave the build command empty with the publish directory set to the repo root.

## GitHub Pages
Push these files to the repository root, then Settings, Pages, Deploy from a branch, root folder. `.nojekyll` is included so the site is served as-is.
